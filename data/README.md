# Datos ESS incluidos

Esta carpeta contiene los archivos utilizados por el análisis:

- **Datafile-subset.csv**: extracto de España con 21.296 respuestas de las rondas 1 a 11. La variable netustm tiene respuestas analizables en las rondas 8 a 11.
- **Datafile-subset codebook.html**: descripción de las variables y ediciones; incluye los DOI de las rondas.

Fuente: [ESS Data Portal](https://ess.sikt.no/en/series/321b06ad-1b98-4b7d-93ad-ca8a24e8788a).
